Anmelden

Melde dich mit einem GitHub Personal Access Token an, um deine Bäume geräteübergreifend zu speichern.

Wie bekomme ich einen Token?
  1. Auf GitHub: github.com/settings/tokens/new öffnen (Link setzt „gist"-Berechtigung schon vor)
  2. Ablaufdatum wählen, ganz unten „Generate token" klicken
  3. Den erzeugten Token (beginnt mit ghp_) kopieren und hier einfügen

Der Token wird nur lokal in deinem Browser gespeichert und ausschließlich für „gist"-Zugriff verwendet.
